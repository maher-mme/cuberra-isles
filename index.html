⬇️ Installer sur Windows

  1. Clique sur Installer pour Windows.
  2. Ouvre le fichier CuberraIsles.exe téléchargé : il n'y a rien d'autre à installer.
  3. Si Windows affiche « Windows a protégé votre ordinateur », clique sur « Informations complémentaires » puis « Exécuter quand même ».

🔄 Les mises à jour sont automatiques : le jeu les télécharge pendant que tu joues, et les installe quand tu le fermes. Tes sauvegardes sont gardées.

⬇️ Installer sur Android

  1. Appuie sur Installer pour Android.
  2. Ouvre le fichier CuberraIsles.apk téléchargé.
  3. Si le téléphone le demande, autorise l'installation d'applications depuis ton navigateur.

▶️ Jouer directement ici

  1. Appuie sur Jouer et attends le chargement (environ 80 Mo, la première fois).
  2. Sur iPhone, iPad et Android : tourne l'écran à l'horizontale. Le joystick est à gauche, les boutons à droite.
  3. Sur Mac et ordinateur : joue au clavier (les commandes sont juste en dessous).

🧪 La version navigateur est toute nouvelle : si quelque chose ne marche pas, signale-le !
